## 📥 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/PortfolioWebsite.git
```

Go to the project folder:

```bash
cd PortfolioWebsite
```

Compile SCSS:

```bash
sass assets/scss/style.scss assets/css/style.css --watch
```

Open `index.html` in your browser.
