# 🌐 Personal Portfolio Website

A modern, responsive personal portfolio website built using **HTML5**, **CSS3**, **SCSS**, **Bootstrap 5**, and **JavaScript**. This project showcases my skills, projects, certifications, and contact information with a clean, glassmorphism-inspired UI.

## 📥 Installation

Clone the repository:

```bash
git clone https://github.com/ajmalmyaseen/PortfolioWebsiteV2.git
```

Go to the project folder:

```bash
cd PortfolioWebsiteV2
```

Compile SCSS:

```bash
sass assets/scss/style.scss assets/css/style.css --watch
```

Open `index.html` in your browser.
